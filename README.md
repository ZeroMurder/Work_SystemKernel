
Вопрос 1. 
-----------------------------------------
Почему отсутствие Spooler в SafeBoot\Minimal препятствует её запуску в безопасном режиме?
В безопасном режиме Windows использует специальный набор разрешённых служб и драйверов, определяемый ветвью реестра HKLM\SYSTEM\CurrentControlSet\Control\SafeBoot\Minimal. Для запуска служб учитываются их записи в этом наборе и зависимости.
Если служба Spooler не зарегистрирована в разрешённом наборе, обычная конфигурация автозапуска не делает её автоматически разрешённой в безопасном режиме. Таким образом, автозапуск и разрешение на работу в Safe Mode — разные механизмы. При этом отсутствие ключа Spooler в Minimal само по себе не исключает все возможные способы её запуска и не означает, что служба отсутствует в других конфигурациях SafeBoot.Таким образом есть много различных методов системных и обычных настроек системы и их редактирования для более удобной системы использования пользователем.

Вопрос 2. 
------------------------------------------------------------------
Когда необходимо настраивать автоматическое восстановление службы?
Правила восстановления следует задавать для служб, которые должны работать длительное время без постоянного участия администратора. Например, это серверные модули, агенты мониторинга, службы обмена данными, фоновые обработчики и корпоративные приложения.
При неожиданном завершении такой службы Windows может автоматически попытаться перезапустить её от уровня системы. Это уменьшает время простоя, сокращает необходимость ручного вмешательства и повышает доступность программного обеспечения.
Однако автоматический перезапуск не устраняет причину сбоя, могут быть выявлены другие  ошибки системы нарушавшие работоспособность программы либо самого По. Если служба постоянно завершается из-за ошибки конфигурации, нехватки памяти или программного дефекта, необходимо дополнительно анализировать журналы событий и исправлять первопричину, только аккуратно не затрагивая опасные комплектующие системы и их файлы,если не соблюдать правила безопасности, может быть нарушена само ядро системы и тогда уже даже восстановление не поможет.

Вопрос 3. 
---------------------------------------------------------------------------------
Как безопасный режим помогает восстановить компьютер после BSoD, вызванного драйвером?
Безопасный режим загружает Windows с ограниченным набором драйверов и служб. Если неисправный сторонний драйвер не загружается в этом режиме, появляется возможность выполнить восстановительные действия без повторения сбоя, вызванного именно этим драйвером.
Инженер может действовать следующим образом:
1. Запустить среду восстановления Windows (WinRE).
2. Выбрать «Поиск и устранение неисправностей» → «Дополнительные параметры» → «Параметры загрузки» → «Безопасный режим».
3. Удалить проблемное программное обеспечение или драйвер через диспетчер устройств либо штатный деинсталлятор.
4. Если требуется, отключить соответствующую службу или драйвер, предварительно определив его точное имя и расположение.
5. Перезагрузить компьютер в обычном режиме и проверить стабильность работы.
Если Windows не загружается даже в безопасном режиме, можно использовать восстановление системы, удаление последних обновлений или другие инструменты WinRE. Вручную удалять системные драйверы без проверки их назначения не рекомендуется, поскольку это может сделать систему неработоспособной.


В ходе лабораторной работы были изучены механизмы ограничения запуска служб и драйверов Windows в безопасном режиме, а также параметры восстановления служб после аварийного завершения. 
С помощью реестра была исследована ветвь SafeBoot\Minimal и проверено отсутствие записи службы печати Spooler в данной конфигурации. 
В оснастке управления службами были настроены действия восстановления при сбоях. 
Работа показала, что безопасный режим помогает диагностировать проблемы с драйверами, а автоматический перезапуск служб повышает доступность программного обеспечения, но не заменяет устранение причин неисправностей.
